Detailed description:
Ever wondered "what is this website built with?" Website Framework Detector tells you in one click — the CMS or website builder, the theme, the full front-end tech stack, and the marketing/analytics tools a site loads. A fast, private, free alternative to heavyweight tools — with no account and no data collection.

✅ DETECTS 44 CMS, BUILDERS & E-COMMERCE PLATFORMS
WordPress, WooCommerce, Shopify, Wix, Webflow, Squarespace, Joomla, Drupal, Magento/Adobe Commerce, PrestaShop, BigCommerce, OpenCart, Shopware, Salesforce Commerce Cloud, Ghost, Blogger, HubSpot CMS, Framer, Craft CMS, Duda, TYPO3, Sitecore, Adobe Experience Manager, Odoo, Weebly, GoDaddy, Tilda, Jimdo, Kajabi, Teachable, Substack, Notion, Docusaurus, GitBook and more — with a real confidence score and the evidence behind it.

✅ WORDPRESS THEME & PLUGIN DETECTOR
Shows the active theme (and parent theme) plus every plugin the page loads, with versions — Elementor, Divi, Yoast SEO, Rank Math, WP Rocket, Contact Form 7, WPML and hundreds more.

✅ SHOPIFY THEME & APP DETECTOR
Theme name, Theme Store ID and store domain, plus apps like Klaviyo, Judge.me, Yotpo, Loox, ReCharge, PageFly and GemPages.

✅ TECH STACK CHECKER
React, Preact, Vue, Angular, Svelte, Solid, Qwik, Next.js, Nuxt, Remix, Gatsby, Astro, Hugo, Jekyll, jQuery, Tailwind CSS, Bootstrap, Three.js, GSAP, Stripe, and more.

✅ THEME DETECTION
Reveals the active theme/template where the platform exposes it.

✅ GA4, GTM & PIXEL CHECKER — WITH IDs
See which tags are installed and copy their IDs: GA4 (G-…), Google Tag Manager (GTM-…), Google Ads (AW-…), Meta Pixel, plus Hotjar, Clarity, HubSpot, TikTok, LinkedIn, Pinterest, Matomo, Plausible, PostHog and more.

✅ WIDGETS & SERVICES
Payments (Stripe, PayPal, Razorpay, Cashfree, PhonePe, Klarna), live chat (Intercom, Tawk.to, Crisp, Zendesk, WhatsApp), cookie consent, reCAPTCHA, maps, video and monitoring tools.

✅ HOSTING, SERVER & SECURITY
Cloudflare, Vercel, Netlify, AWS, WP Engine, Kinsta, Hostinger and 20 more, the web server and PHP version, and six key security headers.

✅ SITE HEALTH IN ONE GLANCE
Catches costly mistakes: a page set to noindex, robots.txt blocking Google, missing HTTPS or mixed content, missing title/description/H1, canonical pointing elsewhere, no sitemap, end-of-life PHP.

✅ A REAL DASHBOARD, NOT A TINY POPUP
A large, app-style window with sections for Overview, Tech stack, Marketing, SEO health, Security and History, a 0–100 health score, keyboard shortcuts, and a full-report tab view.

✅ BUILT FOR REAL WORK
• Auto-detects the moment you open it — one click to re-scan
• Copy a ready-to-paste Markdown report (Slack, Notion, Jira, email) or export JSON
• Clickable history of your last 50 scans with CSV export, plus a personal collection of every platform you've discovered
• Toolbar badge and Alt+Shift+D shortcut
• Wrong result? Report it in one click so it gets fixed
• Light & dark mode
• Real brand logos for instant recognition

🔒 PRIVATE BY DESIGN
Everything runs locally in your browser. No account, no servers, no tracking, no data collection. Only the minimal "activeTab" access, and the extension runs only when you click it — never silently in the background.

PERFECT FOR
Web developers, designers, SEO specialists, marketers, agencies, and the simply curious who want to know what platform and technologies power any website.

HOW IT WORKS
1) Open any website  2) Click the icon  3) See the platform, theme, tech stack, and analytics tags.

Open source (GPLv3). Made by Anupam Mondal.
