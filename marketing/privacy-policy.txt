PRIVACY POLICY - WEBSITE FRAMEWORK DETECTOR CHROME EXTENSION
Last Updated: August 11, 2026

Created and maintained by Anupam Mondal (https://anupammondal.in).

WHAT THIS EXTENSION DOES
Website Framework Detector runs only when you click its toolbar icon or
press its keyboard shortcut, on the single tab you are currently viewing.
When run, it reads publicly visible website content on that page - HTML
markup, script tags, meta tags, and response headers - to identify the
CMS, site builder, theme, and front-end tech stack the site is built
with. This is the same information already visible in the page's source,
and it is read locally in your browser. It is never transmitted to the
developer or to any third party.

INFORMATION WE DO NOT COLLECT
This extension does NOT collect, transmit, sell, or share:
  - Personally identifiable information (name, address, email, etc.)
  - Health information
  - Financial or payment information
  - Authentication information (passwords, credentials, PINs)
  - Personal communications (emails, texts, chat messages)
  - Location data
  - Web/browsing history
  - User activity (clicks, keystrokes, mouse movement, network monitoring)

The extension has no backend servers of its own and makes no network
requests other than fetching the current page's own response headers -
a request the page itself could already make.

LOCAL STORAGE
The extension uses your browser's local storage (chrome.storage.local)
only to remember, on your own device:
  - your light/dark theme preference
  - a private history of up to 25 recently scanned sites (site host,
    detected platform, and timestamp) so you can review past scans
  - a couple of internal flags used to show a one-time review prompt

This data never leaves your device, is never synced to a server, and is
never seen by the developer. It can be cleared at any time from the
extension's history panel or by removing the extension.

PERMISSIONS
  - activeTab / scripting: used only on user action (clicking the icon or
    using the keyboard shortcut) to read the current tab's page content
    for detection. No content script runs automatically or in the
    background, and no host permissions are requested.
  - storage: used only for the local preferences and history described
    above.

CHANGES TO THIS POLICY
Any updates or revisions to this privacy policy will be documented here
to ensure ongoing transparency and user trust.
